Выводы

a) Анализ результатов

В ходе выполнения практической работы были реализованы алгоритмы редукции и сканирования на GPU с использованием CUDA. Экспериментальные результаты показали корректность работы алгоритмов, что подтверждается совпадением результатов CPU и GPU вычислений для всех протестированных размеров массивов.

b) Сравнение производительности CPU и GPU

С увеличением размера массива время выполнения на CPU растёт линейно, тогда как GPU демонстрирует значительно меньший рост времени выполнения. Для больших массивов GPU существенно превосходит CPU по производительности, особенно в задачах редукции, где эффективно используется параллельная обработка и разделяемая память.

c) Рекомендации по оптимизации

Для дальнейшего повышения производительности рекомендуется:
	•	использовать разделяемую память для уменьшения количества обращений к глобальной памяти;
	•	оптимально подбирать размер блоков и сетки потоков;
	•	минимизировать количество синхронизаций между потоками;
	•	применять многоступенчатые алгоритмы редукции и сканирования для очень больших массивов.

В целом, использование GPU является оправданным и эффективным решением для вычислительно интенсивных задач обработки массивов данных.
